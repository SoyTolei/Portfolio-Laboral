Perfil

Analista de soporte técnico. Criterio de trabajo: incidentes resueltos de raíz, entornos estables y casos documentados para quien retome el seguimiento.

En Thomson Reuters, soporte técnico de Bejerman a empresas y estudios contables: instalaciones, SQL Server y operación de mesa de ayuda.

ST2 (Soluciones Tecnológicas) es una suite interna en C# / .NET y PowerShell: portal web del agente, herramientas SQL de escritorio y consola de campo. Cubre planillas, blanqueo, PDFs, backups, trazas y diagnóstico de instalaciones.

// enfoque

Herramientas compartidas y procedimientos consistentes, en lugar de conocimiento que queda en una sola persona. La suite se mantiene activa y se publica por módulo en GitHub.

Las herramientas ST2 no representan productos ni posiciones oficiales de Thomson Reuters.

Proyectos

Suite ST2 para la mesa de ayuda, más un proyecto personal. Iniciativa interna; no es un producto de Thomson Reuters.

Las herramientas ST2 no representan productos ni posiciones oficiales de Thomson Reuters.

Suite ST2

st2.tolei.dev ↗ ST2-WEB ↗

ST2 WEB

Portal del agente en el navegador: planillas (transferencia, referral I+D, oportunidad), blanqueo de accesos, generador de PDFs A4, Portal Cliente, THOM, AI Platform y panel de accesos por usuario.

ASP.NET Core 9 · JavaScript · REST

ST2-Herramientas-SQL ↗

ST2 — Herramientas SQL

App Windows para bases Bejerman: conexión por registro, backup y restore, backups programados, editor T-SQL con scripts frecuentes, traza tipo Profiler (Extended Events) e IA que explica consultas y errores con el esquema de la base.

C# · WinForms · .NET 8 · T-SQL · Extended Events · IA (Groq)

ST2-BAT ↗

ST2 BAT — Mantenimiento Bejerman

Consola de campo en PowerShell 5.1: planilla técnica, registración (DLL, Crystal, TLB, DCUBE), herramientas TEC y informe de sesión. Entregable ST2-PS.bat, sin instalar nada en el puesto.

PowerShell 5.1 · Registro Windows
